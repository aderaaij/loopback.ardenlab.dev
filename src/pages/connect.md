<div class="summary"><p>This link connects the Loopback app to a server. You are reading this page because it opened in a browser and not in the app. Nothing has been connected yet.</p></div>

## If Loopback is on this phone

Open Loopback, tap **Scan QR Code** on the sign-in screen and point it at the code in your server's dashboard.

If the dashboard is open on this same phone, go back to it and touch and hold **Open in Loopback on this phone**, then choose **Open in "Loopback"**.

## If it isn't yet

Install Loopback from the [TestFlight beta](https://testflight.apple.com/join/fV73tucs), then scan the code from the app's sign-in screen. A code works once and for five minutes, so show a new one in the dashboard: **Settings → Phone app → Show QR code**.

## What this page was sent

Nothing from the link. The server's address, the account name and the one-time code come after the `#` in the link, and a browser keeps that part to itself: it is not sent to this site. The [privacy policy](/privacy/) has the details, and the [support page](/support/) has help with connecting.
